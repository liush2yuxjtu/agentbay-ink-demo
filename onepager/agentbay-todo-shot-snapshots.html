SVG 子产物 / AgentBay TODO App

每个分镜一张可直接查看的画面快照。

主拍摄脚本只保留操作窄门；本页集中放 10 张内联 SVG UI mock，可独立打开、截图和交给导演/剪辑。

格式 1200×675 / 16:9 数量 10 个分镜 资源 无外链、无 CDN、SVG 内联

01 · 一句需求，直接开场

自然语言进入共享会话，结果目标先于解释出现。

00:00–00:05
画面先给输入框和一句需求，不拍密钥配置。
旁白 / 贴片“我想要一个能真正操作的待办应用。”

02 · 沙盒上线

把执行边界画出来：LIVE、镜像和独享会话。

00:05–00:15
画面状态灯、镜像、容量和费用估算同时出现。
旁白 / 贴片“代码不会跑在我电脑上，而是在独享远程沙盒里。”

03 · 工具轨迹出现

把可审计事件当作证据，不展示隐藏思维。

00:15–00:28
画面工具名、动作、完成/执行中状态和远程路径可见。
剪辑保留 2–3 个事件，不让轨迹变成日志墙。

04 · TODO App 成形

代码只短暂出现，重点仍是最小可用 UI。

00:28–00:45
画面左侧出现远程文件，右侧马上回到中文 UI。
注意代码镜头不超过 3 秒，避免变成代码阅读视频。

05 · 发布前验证

展示服务健康，不只展示一个临时 URL。

00:45–00:58
画面目录约束、健康检查和发布状态一眼可读。
旁白 / 贴片“写完还要验证页面能被 HTTP 服务读取。”

06 · 打开浏览器沙盒

从控制台切到远程浏览器中的真实结果。

00:58–01:08
画面浏览器地址只作为环境证据，焦点放在可操作 UI。
旁白 / 贴片“现在进入同一个远程浏览器沙盒，像真实用户一样操作。”

07 · 添加三条任务

用可读数据制造状态变化，让交互有证据。

01:08–01:22
动作输入三条中文任务，保留鼠标和焦点移动。
贴片ADD TASK · 3 ITEMS

08 · 完成、筛选、删除

三种状态证明它不是静态页面。

01:22–01:35
动作勾选一条、切换“未完成”、删除一条。
旁白 / 贴片“结果能被操作，才算完成。”

09 · 反馈继续迭代

把一条具体意见送回当前会话，不重新解释项目。

01:35–01:52
动作输入一条具体反馈，等待 Agent 继续修改。
注意反馈不公开临时 authcode，不把链接当长期交付物。

10 · 安全回收

用归档和 STOPPED 状态结束，不用口号结束。

01:52–02:00
动作停止预览或执行 /exit，保留 STOPPED 2 秒。
旁白 / 贴片“用完归档、回收沙盒；下一次还能恢复会话。”
